# Data Model: User Accounts

**Feature**: [spec.md](./spec.md) | **Research**: [research.md](./research.md) | **Date**: 2026-11-06

All tables are created by Alembic migrations only. All timestamps are `timestamptz` stored in UTC.

## Enums

| Enum | Values |
|------|--------|
| `account_role` | `member`, `admin` |
| `account_status` | `active`, `deactivated` |
| `status_change_action` | `deactivated`, `reactivated` |

## account

A person registered in LendLoop (spec: **Account**).

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | `uuid` | PK | UUIDv4, generated by the app (R12) |
| `email` | `varchar(254)` | NOT NULL, UNIQUE | Stored normalized: trimmed and lowercased (FR-002, R6) |
| `password_hash` | `text` | NOT NULL | Argon2id encoded hash (FR-005, R3). Never returned by any endpoint |
| `display_name` | `varchar(50)` | NOT NULL, CHECK `char_length(display_name) BETWEEN 1 AND 50` | Trimmed before storage; not unique (FR-010) |
| `neighborhood_area` | `varchar(100)` | NULL | Trimmed; empty input stored as `NULL` |
| `role` | `account_role` | NOT NULL, default `member` | New registrations are always `member` (FR-014) |
| `status` | `account_status` | NOT NULL, default `active` | Active immediately on registration (FR-003) |
| `created_at` | `timestamptz` | NOT NULL, default `now()` | Registration date |
| `updated_at` | `timestamptz` | NOT NULL, default `now()` | Set by the app on every change |

**Validation (API layer, R17)**: email is a valid address of at most 254 characters; password is
12–128 characters with no other rules; display name 1–50 characters after trimming;
neighborhood area at most 100 characters after trimming.

**State transitions** (`status`):

```text
            register
               │
               ▼
   ┌──────── active ◄────────┐
   │                         │
   │ admin deactivates       │ admin reactivates
   │ (not own account)       │ (not own account)
   ▼                         │
 deactivated ────────────────┘
```

- Both transitions are performed only by an administrator, never on their own account (FR-016).
- Each transition writes one `account_status_change` row in the same transaction (FR-020, R13).
- Deactivation deletes all of the account's `session` rows in the same transaction (FR-017).
- Requesting a transition to the current state changes nothing and writes no record (R13).

## session

Proof that an account is signed in on one device (spec: **Session**).

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | `uuid` | PK | UUIDv4 |
| `account_id` | `uuid` | NOT NULL, FK → `account.id` ON DELETE CASCADE | Indexed |
| `token_hash` | `char(64)` | NOT NULL, UNIQUE | Hex SHA-256 of the cookie token; the token itself is never stored (R1) |
| `created_at` | `timestamptz` | NOT NULL, default `now()` | |
| `last_seen_at` | `timestamptz` | NOT NULL, default `now()` | Refreshed at most once a minute (R2) |

**Validity rule**: valid while `now() - last_seen_at < interval '7 days'` and the account is
`active`. An expired row is deleted when it is looked up.

**Ended by** (row deleted):

| Event | Sessions deleted |
|-------|------------------|
| Sign-out | The current session |
| Password change | All of the account's sessions except the current one (FR-011) |
| Deactivation | All of the account's sessions (FR-017) |

## sign_in_failure

One failed sign-in attempt, used for throttling (FR-008, R7). Not exposed by any endpoint.

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | `bigint` | PK, identity | |
| `email` | `varchar(254)` | NOT NULL | Normalized email as submitted; no FK because unknown emails are recorded too |
| `client_ip` | `inet` | NOT NULL | From the trusted forwarded address (R7) |
| `attempted_at` | `timestamptz` | NOT NULL, default `now()` | |

**Index**: `(email, client_ip, attempted_at DESC)`.

**Throttle rule**: an attempt for `(email, client_ip)` is refused when the 5 most recent failures
for that pair all fall within 15 minutes of each other and the newest is less than 15 minutes old.
Refused attempts are not recorded. A successful sign-in deletes that pair's rows. Rows older than
15 minutes are deleted when a new failure is written.

## account_status_change

A permanent record of one administrator action (spec: **Account Status Change**).

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | `bigint` | PK, identity | |
| `account_id` | `uuid` | NOT NULL, FK → `account.id` ON DELETE RESTRICT | The affected account. Indexed |
| `admin_id` | `uuid` | NOT NULL, FK → `account.id` ON DELETE RESTRICT | The administrator who acted |
| `action` | `status_change_action` | NOT NULL | |
| `created_at` | `timestamptz` | NOT NULL, default `now()` | Indexed descending for "newest first" |
| | | CHECK `account_id <> admin_id` | Nobody records an action on their own account |

**Immutability**: no endpoint updates or deletes these rows (FR-020). `ON DELETE RESTRICT`
prevents deleting an account that has records.

## Relationships

```text
account 1 ──── * session
account 1 ──── * account_status_change   (as account_id: the affected account)
account 1 ──── * account_status_change   (as admin_id: the administrator)
sign_in_failure: standalone, linked to an account only by email text
```

## Views returned by the API

Database models are never returned directly (constitution III). Response schemas are defined in
[contracts/api.md](./contracts/api.md):

| Schema | Fields | Who sees it |
|--------|--------|-------------|
| `MeResponse` | id, email, display_name, neighborhood_area, role, created_at | The account owner |
| `MemberPublic` | id, display_name, neighborhood_area, is_deactivated | Any signed-in member (FR-012, FR-017) |
| `AdminAccountView` | id, email, display_name, role, status, created_at | Administrators (FR-015) |
| `StatusChangeView` | id, action, created_at, account (id, display_name), admin (id, display_name) | Administrators (FR-020) |
